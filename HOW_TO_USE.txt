PAVAN'S GITHUB PROFILE README PACK

1. Open your GitHub profile and open the repository whose name exactly matches your GitHub username.
2. Upload README.md to the root of that repository.
3. Upload the entire assets folder, keeping all four SVG files inside it.
4. In README.md, replace every YOUR-GITHUB-USERNAME with your exact GitHub username.
5. Replace YOUR-LINKEDIN-USERNAME with your LinkedIn profile username.
6. Commit the changes. GitHub will render the README and local SVG graphics.

Important:
- Keep the paths exactly as assets/hero.svg, assets/pipeline.svg, assets/skyline.svg, and assets/footer.svg.
- The project section describes project ideas to implement; add real repository links and results as you complete them.
- GitHub statistics cards are supplied by third-party services and may occasionally be unavailable.
